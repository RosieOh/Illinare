# 일리네어 상용화 분석

작성일 2026-11-02. "측정"으로 표시한 항목은 이 저장소와 Windows 11 PC에서 직접 확인했습니다. 시장 항목은 2026년 11월 웹 검색 기준이며 상당수가 2차 출처이므로 출시 전 공식 페이지로 다시 확인해야 합니다.

## 결론

**개선 전 상태로는 상용화할 수 없었습니다.** 제품이 아니라 JARVIS 콘셉트 데모였습니다.

**개선 후에는 비공개 베타를 시작할 수 있는 수준입니다. 유료 출시는 아직 아닙니다.** 실제 API 호출을 한 번도 돌리지 못했고, 코드 서명과 사용자 검증이 없습니다.

**"대박"은 코드로 보장할 수 없습니다.** 가장 큰 위험은 시장에 있습니다. Anthropic과 Microsoft가 같은 영역에 이미 들어와 있습니다. 넓은 시장의 범용 AI 비서로 정면승부하면 이기기 어렵고, 좁은 쐐기 시장을 먼저 잡아야 승산이 있습니다.

## 개선 전 진단 (측정)

| 영역 | 발견 | 영향 |
| --- | --- | --- |
| 플랫폼 | 도구 26개 대부분이 macOS 전용 바이너리에 의존. `/usr/bin/osascript` 등 8개 경로 모두 Windows에서 ENOENT | Windows에서 AI가 사실상 아무것도 못 함 |
| 파일 도구 | `safePath`가 `HOME + '/'`로 검사. `~/Desktop`이 Windows에서 "홈 밖"으로 거부됨 | Windows에서 파일 도구 전부 실패 |
| 가짜 데이터 | 상단 "보안" 배지가 `Math.random()`. "2.4 TFLOPS", "99.97% 가동률", "방어 시스템 무장완료", "에너지 91%", "256-bit AES", "양자 내성 암호화"가 모두 지어낸 값 | 실제 판매 시 허위 표시 소지. 신뢰를 근본적으로 훼손 |
| 승인 우회 | 서버가 클라이언트가 보낸 `messages`와 `decisions`를 그대로 신뢰. 위조한 tool_use + approve로 임의 도구 실행 가능 | 승인 체계가 형식에 그침 |
| AppleScript 인젝션 | `delete_file`이 `"`만 이스케이프하고 `\`는 처리하지 않음 | 경로로 임의 명령 실행 가능 |
| 차단 목록 | `.env`, `.npmrc`, `.netrc`, 브라우저 프로필 미차단. 심볼릭 링크 미검사. macOS에서 `~/.SSH`로 대소문자 우회 가능 | 비밀 유출 경로 |
| 무단 민감 동작 | 클립보드 읽기, 스크린샷이 승인 없이 실행 | 프롬프트 인젝션에 취약 |
| 공급망 | MediaPipe를 CDN에서 범위 버전(`@0.4`)으로 로드, SRI 없음 | 원격 코드 실행 위험, 오프라인 불가 |
| 대화 유실 | 서버 오류 응답의 `messages: []`가 클라이언트 기억을 지움. 승인 대기 중 새 메시지를 보내면 API 400 | 데이터 손실, 막다른 상태 |
| 키보드 | 슬라이드 뷰가 숨겨져도 전역 방향키를 가로챔 | 입력 중 방향키가 슬라이드를 넘김 |
| 지속성 | 새로고침하면 대화 소멸. 응답 스트리밍 없음. 파일/앱 작업 되돌리기 없음 | 실사용 불가 수준 |
| 배포 | `git clone` + `npm run dev` + 환경변수. 온보딩, 패키징, 업데이트 없음 | 일반 사용자 설치 불가 |
| 품질 | 테스트 0개, ESLint 오류 11개, 기본 README, 패키지명 `jarvis` | 유지보수 위험, Marvel/Disney 상표 연상 |

### 정직한 평가
- **BYOK는 대중 시장에서 불리합니다.** API 키 발급은 큰 진입 장벽이고, 사용량 과금은 정액제보다 비싸게 느껴집니다.
- **"AI가 내 컴퓨터를 제어한다"는 범용 기능만으로는 차별화되지 않습니다.** 대형 플랫폼이 무료 또는 저가로 제공합니다.
- **제스처 제어는 시연 효과는 크지만 일상 가치는 작습니다.** 판매 포인트가 아니라 발표 전용 기능으로 다뤄야 합니다.

### 이길 수 있는 쐐기 시장
1. **한국 사무 환경 특화.** HWP/HWPX 문서, 공문 서식, 한국어 보고서 양식, 국내 서비스 연동은 글로벌 업체의 우선순위 밖입니다. 가장 유력합니다.
2. **통제와 감사가 필요한 사용자.** 행동별 승인, 파일 되돌리기, 감사 기록, 비용 상한을 전면에 내세웁니다. 규제 업종의 개인과 소규모 팀, 보안에 민감한 1인 사업자가 대상입니다.
3. **과정이 보이는 에이전트.** 무슨 일이 왜 일어나는지 실시간으로 보이는 경험은 차별점이며, 데모 영상으로 전달하기 좋습니다.

### 권장 사업 모델
- 앱은 일회성 구매 또는 낮은 연 구독, API 비용은 사용자 부담(BYOK)으로 시작합니다. 서버 비용이 없어 초기 마진 위험이 낮습니다.
- 다음 단계로 키 없이 쓸 수 있는 크레딧 요금제를 검토합니다. Anthropic 재판매 조건, 결제, 약관을 먼저 확인해야 합니다.
- 데모 모드를 첫 경험으로 활용합니다. 키 없이 가치를 느낀 뒤 키를 등록하게 합니다.

## 출시 전 사람이 해야 할 일 (코드로 해결 불가)

1. **상표 조사.** "일리네어/Illionaire"는 2011년 설립된 [더콰이엇·도끼의 힙합 레이블 일리네어 레코즈](https://cavac.at/cavacopedia/Illionaire%20Records)와 겹칩니다. 2020년 활동 종료로 보도되었으나 상표권 상태는 확인하지 못했습니다. [KIPRIS](https://www.kipris.or.kr)와 WIPO에서 조회하고 변리사 검토를 받으세요. 이름은 `lib/contracts.ts`의 `BRAND`를 바꾸면 UI 전체에 반영됩니다. 데스크톱 빌드는 `electron-builder.yml`과 `electron/main.mjs`의 `APP_TITLE`도 바꿔야 합니다.
2. **"Apple Glass" 표현.** Liquid Glass의 시각 언어를 참고하는 것은 일반적이지만, Apple 로고, SF Pro 폰트 파일, "Apple 공식" 같은 표현은 쓰면 안 됩니다. 이 앱은 쓰지 않습니다. 마케팅 문구에서도 피하세요.
3. **실사용자 검증.** 대상 사용자 10~20명과 인터뷰하고 베타를 돌리기 전에는 수요를 안다고 말할 수 없습니다. 이 분석은 사용자 조사를 대체하지 못합니다.
4. **실제 API 검증 (가장 먼저).** 이 PC에 API 키가 없어 실제 Claude 호출은 한 번도 실행하지 못했습니다. 첫 실행에서 문제가 나올 가능성이 높습니다. 웹 검색, 코드 실행, 폴백, PDF 첨부를 포함한 미션을 끝까지 돌려 보세요.
5. **코드 서명과 공증.** Windows 코드 서명 인증서, Apple Developer ID 공증이 없으면 설치 시 보안 경고가 뜹니다.
6. **macOS 실기 테스트와 실제 Linux 데스크톱 확인.** macOS 코드는 한 번도 실행하지 못했습니다. Linux는 컨테이너에서만 실행했습니다.
7. **법무.** 이용약관, 개인정보 처리방침(파일 내용이 Anthropic API로 전송됨을 명시), Anthropic 이용 정책 준수 여부, 전자상거래법 표시 사항.
8. **결제와 라이선스, 자동 업데이트 서버, 오류 수집 동의 절차.**
9. **비용 경험 검증.** 기본 모델은 Opus 5.5이고 미션당 기본 상한은 $2입니다. 실제 미션 비용을 재서 기본값을 정하세요. 상한은 근사치입니다.
10. **접근성 실사용 검증.** 스크린 리더 사용자 테스트.
